# **App Name**: Seven Properties Bespoke

## Core Features:

- Property Showcase: Display Seven Properties' ultra-luxury real estate offerings with high-resolution images and detailed descriptions of the properties located in Ikoyi, Banana Island, and Victoria Island.
- HNWI Targeted Content: Deliver emotive and aspirational content that resonates with the values and aspirations of high-net-worth individuals, reinforcing exclusivity and developer pedigree.
- SEO Optimization: Optimize the one-page website for high-intent, low-competition luxury real estate and investment keywords relevant to Lagos, improving search engine rankings.
- Diaspora Focus: Target Nigerian HNIs and UHNIs living abroad with tailored messaging that highlights investment opportunities and addresses their unique concerns.
- Architectural Excellence Emphasis: Use detailed descriptions and architectural renderings, emphasize architectural brilliance.
- AI-Powered Keyword Tool: Employ a tool that uses generative AI to automatically incorporate low-competition real estate keywords.

## Style Guidelines:

- Primary color: Deep Navy Blue (#192A56) to evoke trust, stability, and sophistication.
- Background color: Soft Beige (#F5F5DC) to offer a calm, luxurious backdrop without distracting from the content.
- Accent color: Muted Gold (#A98D67) to highlight key details and calls-to-action, conveying prestige.
- Body font: 'Alegreya', a serif typeface for a distinguished literary and contemporary feel in body text.
- Headline font: 'Belleza', a sans-serif for personality that pairs perfectly with 'Alegreya', offering elegance to titles.
- Use minimalist line icons to represent key features like security, location, and amenities. Icons should appear in the muted gold accent color.
- Implement a clean, spacious layout with ample whitespace to provide an uncluttered and elegant user experience.
- Subtle fade-in animations on scroll to gently reveal content and maintain user engagement without overwhelming.
